Windows 11 界面重做版。仅支持 Windows 11 x64（内部版本 22000 及以上），不再兼容 Windows 10。macOS 版保留独立的原生界面。

- 移除 Tk 界面，改为 Qt 6 实现的 Fluent 风格工作台：统一深色控件、圆角卡片、轻量滚动条、清晰的详情与日志布局。
- 保留 Windows 原生标题栏、窗口缩放、阴影和最大化按钮的贴靠布局；通过公开 DWM API 请求深色标题栏、圆角与 Mica（Mica 需要 Windows 11 22H2 及以上，并服从系统设置）。
- 使用 Segoe UI Variable / 微软雅黑 UI 字体，支持高 DPI 缩放。
- 三段胶囊切换浅色、深色或跟随系统，使用单色矢量图标，保存选择并同步终端配色；换主题不重建终端会话。
- 保留性能监控、进程搜索/CPU 排序、启动项与日志。
- 重写应用内终端界面：可关闭和拖动排序的 CMD / PowerShell 标签，切换页面继续运行，支持 Ctrl+C、复制粘贴、颜色和窗口尺寸变化。
- 内置 Python、Qt 与终端依赖，下载 EXE 后双击运行。

本版是 Qt 实现的 Windows 11 风格界面，并非 WinUI。下载 `.exe` 或带说明和第三方许可的 `.zip`，校验值见 `SHA256SUMS-Windows.txt`。

退出应用会停止托管任务与终端。配置与日志保存在 `%LOCALAPPDATA%\LocalDeck`。程序不请求管理员权限，受保护进程可能无法读取或停止。该版本尚未做 Authenticode 签名。

- 终端文件面板可收起，支持右键 cd、新建文件、重命名、复制路径及回收站。
- 修复新输出打断历史日志阅读的问题，回到底部恢复跟随。
- 新增圆形设置入口及开发者 GitHub 主页卡片。
