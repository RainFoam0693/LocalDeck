LocalDeck 0.5.0 for Windows 11 x64

Double-click LocalDeck.exe to launch. Python, Qt 6 and terminal dependencies are bundled.
Requires Windows 11 build 22000 or newer. Windows 10 is no longer supported.
Native Windows caption buttons preserve Snap Layouts, resizing and system shadows.
Dark caption, rounded corners and Mica are requested through public DWM attributes.
Mica requires Windows 11 22H2 or newer and follows system accessibility/composition settings.
The interface uses a Fluent-inspired Qt layout (not WinUI), with Windows UI fonts,
rounded cards, consistent dark controls and high-DPI scaling.
No administrator privileges requested. Place the EXE on your desktop if desired.

Running services: TCP listeners, PID, ports, command line and working directory.
Managed tasks: create a command, start, stop, restart and view recent logs.
Commands run through cmd.exe /d /s /c, using your current PATH.
Built-in terminals: multiple CMD/PowerShell tabs, live VT output, keyboard input,
Ctrl+C, Ctrl+Shift+C/V, working directory selection and resize.
Tabs keep running while other app pages are selected.
Closing a terminal tab stops its shell and children. App exit closes all terminals.

Configuration and logs: %LOCALAPPDATA%\LocalDeck
Closing the app stops tasks started by LocalDeck.
External services are not stopped on exit.
Protected processes may not expose command lines or directories.
Detached tasks (for example "start") may outlive the managed shell.
Log files currently do not rotate automatically.

This EXE is not Authenticode signed. Verify SHA256SUMS-Windows.txt.
Third-party license notices and rebuilding information are included in the ZIP.
